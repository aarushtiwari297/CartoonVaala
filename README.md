📺 Cartoon Vaala

A nostalgic web experience inspired by the golden era of Indian children's television.

Cartoon Vaala is a frontend project built around the memories of growing up with cartoons in the late 1990s and 2000s — coming home from school, switching on the TV, listening to familiar title tracks, and spending the afternoon with favourite shows.

The project combines a retro television aesthetic, cartoon archive, music player, and nostalgic storytelling into one interactive experience.

✨ Features

📺 CRT-inspired broadcast/player interface

🎵 Cartoon audio and title-track experience

🖼️ Cartoon image archive

📡 Network-based cartoon browsing

🕓 Nostalgic "4:00 PM" memory experience

📚 Dedicated nostalgic memory/library section

🎛️ Interactive playback controls

📱 Responsive design for desktop and mobile

⚡ Lightweight frontend with no unnecessary dependencies

🛠️ Tech Stack

HTML5

CSS3

Vanilla JavaScript

HTML5 Audio

Vercel for deployment

🚀 Run Locally

Clone the repository:

git clone https://github.com/aarushtiwari297/CartoonVaala.git

Open the project in VS Code and run index.html using Live Server.

Alternatively:

python -m http.server 5500

Then visit:

http://localhost:5500
